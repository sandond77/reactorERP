Alerts

Automated reminders + triggered notifications. Tell Reactor what events you want to know about; it surfaces them when they happen.

Alert types

  • Aging inventory — a card has been unsold for N days.
  • Grading return overdue — a submission has been shipped longer than its expected return.
  • Listed but not sold — a listing has been active for N days without a sale.
  • Awaiting intake — bulk orders received but never inspected.
  • Custom thresholds — set by you (e.g. "alert if any single card has been on show table 90+ days").

Common actions

  • + New Alert — pick a type, set a threshold, give it a name.
  • Click a row — edit thresholds or disable.
  • Snooze — silence an alert for N days without disabling.

Where alerts surface

  • Dashboard banner — active alerts show at the top of the dashboard.
  • Email (optional) — daily digest of new alerts if configured.
  • AI Agent can read active alerts and report on them: "what's overdue?"
