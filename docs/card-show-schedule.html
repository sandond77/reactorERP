Show Schedule

Every card show — past, current, and upcoming. The directory of card_shows entries.

What you see

Columns: Name, Location, Start date, End date, Days (count), Status (upcoming / live / past), Total sales, Total profit (for past shows).

Common actions

  • + New Show — name it, set the date range (single or multi-day), location.
  • Click a row — opens the show detail. See per-day sales, total inventory brought, edit dates or location.
  • Delete a show — only allowed if there are no sales tied to it. Otherwise, archive instead.

Tips

  • Set up shows before you go so you can record sales with the correct show + day at the time of sale (not after the fact).
  • For multi-day shows, sales let you pick which day the transaction belongs to. The Reports Card Show Breakdown can slice by day.
