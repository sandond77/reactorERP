Graded / Slabs

The complete graded inventory table. One row per slab. Filter, search, sort, export.

What you see

Every card_instances row joined to slab_details. Columns include Part #, Cert #, Card Name, Grade, Company, Condition, Listed price, Cost basis, Strike price (if sold), Net, ROI, dates, location, notes.

Common actions

  • Search — by card name, cert #, or part #.
  • Column filters — every column header has a filter dropdown (grade, company, listed status, card show flag, etc).
  • Sort — click a column header.
  • Click a row — opens the Slab Detail modal. Edit identity (card name, cert, grade, label), grading cost, location, personal-collection flag, or delete.
  • + Add Slab — add a single graded card manually (pre-graded purchase flow). Enter cert + grade + cost basis.

Filters worth knowing

  • All / Unsold / Sold top tabs.
  • Personal — toggles cards flagged is_personal_collection = true (your keeper inventory; excluded from for-sale views).
  • Card Show? column filter shows on-show inventory only.

Tips

  • Cost basis discrepancies — if a slab's raw_cost + grading_cost doesn't match its Cost column, check if the source raw lot or grading batch was edited after the slab was created.
  • Stale listing data — if a slab shows "Listed: Yes" but you can't find the listing, check the Listings page; the listing might have been cancelled mid-edit.
