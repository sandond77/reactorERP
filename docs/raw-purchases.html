Raw Purchases

The order log — every raw or bulk purchase you've placed. The entry point for raw inventory.

What you see

One row per raw_purchases record. Columns: Purchase ID, Type (raw/bulk), Source, Order #, Card name (raw single) or set (bulk), Card count, Total cost USD, Purchased date, Received date, Status.

Status moves through ordered → received → cancelled. received_at being set is what flips status to received.

Common actions

  • + Add Raw Purchase — manual order entry. Pick raw (single card, qty=1) or bulk (lot of N).
  • Click a row — opens the purchase detail. Edit cost, dates, source, type, or status.
  • Mark received — sets received_at + flips status. For raw orders, this auto-creates a matching card_instance.
  • Upload receipt — attach a receipt URL or image for record-keeping.

Raw vs Bulk

  • Raw single (type=raw): each order = one card. The card_instance is created at receive time. Cost = order cost.
  • Bulk lot (type=bulk): each order = N cards. No card_instances created automatically — you split them out via Inspection. Cost is allocated proportionally during split.

Awaiting Intake

Bulk orders marked received but not yet inspected show up in the Dashboard's Awaiting Intake counter. Use Inspection to split them.
