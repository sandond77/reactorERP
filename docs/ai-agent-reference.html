AI Agent Reference

Every tool the agent can call, grouped by area. For the concept overview see AI Agent.

Inventory — read

ToolWhat it does
list_inventoryLists card_instances with filters (status, type, search). Used for "show me my unsold PSA 10s."
lookup_catalogResolves a card name / set / number to a Part # (SKU) using the shared card_catalog.
list_locationsLists physical storage locations.

Inventory — write

ToolWhat it does
create_raw_purchaseCreates a new raw_purchases entry. Type raw or bulk.
add_card_to_purchaseSplits a bulk lot — creates a card_instance tied to an existing purchase.
add_graded_cardDirect add for a graded slab. No raw_purchase needed.
update_cardEdits a card_instance: condition, decision, notes, location, etc.
delete_cardRemoves a card_instance. Reversible via audit log.
assign_card_to_locationUpdates location_id. May flip is_card_show flag depending on the destination.
save_imagesAttaches images uploaded in your message to a card_instance.

Sales

ToolWhat it does
list_salesLists sales with filters (platform, date range, card show). Up to 500 rows.
record_saleLogs a single sale.
record_bulk_saleCard-show style — multiple cards under one total.
update_saleEdits an existing sale's fields.
delete_saleRemoves a sale + restores the card to inventory.

Listings

ToolWhat it does
list_listingsLists active listings with filters.
create_listingCreates a new listing on a card.
update_listingEdits URL or price on an existing listing.
cancel_listingMarks a listing cancelled.

Grading

ToolWhat it does
submit_to_gradingRoutes cards to grading + adds them to a batch.
list_grading_batchesLists submissions with their status.
update_grading_batchEdits batch metadata. Cost changes fan out to linked slabs + historical sales.
process_grading_returnProcesses a return CSV. Creates slabs.

Card Shows

ToolWhat it does
list_card_showsLists active + past shows. Used for "what's my next show?"
get_card_show_reportP&L breakdown per show. Multi-day shows prompt for which day.

Expenses + Trades

ToolWhat it does
record_expenseLogs an expense (postage, supplies, fees).
delete_expenseRemoves an expense.
record_tradeLogs a card-for-card trade with both sides + optional cash boot.

Example prompts

  • Logging: "I sold cert 76565619 on eBay for $1500 with $150 in fees and $10 shipping. Order number is 12-34567-89012."
  • Bulk sale: "At Reading I sold 5 PSA 10 commons at $30 each. Card names: ..."
  • Reporting: "What was my P&L for the Reading show day 2?"
  • Searching: "Show me my Charizard inventory. Sort by ROI desc."
  • Bulk update: "Mark these 10 raw cards as for-sale: ..."
  • Editing: "Update the grading batch from yesterday — actual cost was $480 not $500."
