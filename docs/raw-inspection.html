Inspection

Where bulk lots become individual raw cards. Pick a lot, walk the cards, assign condition + routing decision per card.

The flow

  1. Pick a lot. The lot picker shows raw_purchases with unsplit quantity remaining. Filter by received-not-yet-fully-split.
  2. Walk the cards. For each physical card from the lot, fill in:
    • Card name — autocomplete from the catalog. If new, a catalog entry is created.
    • Condition — NM, NM-, LP, LP+, MP, MP-, HP, DMG.
    • Decision — Sell Raw or Submit to Grading.
    • Optional: condition notes, image, location.
  3. Save the split. A new card_instance row is created at qty=1 with cost = lot's per-card cost. The lot's remaining qty decrements.

Bulk-add same-condition rows

If a lot has 20 NM commons that you don't want to inspect individually, use the multi-add form: set condition + decision + quantity (e.g. 20). One card_instance is created at qty=20 instead of 20 separate rows.

Tips

  • Inspection routing is recorded as the decision column on the card_instance. The Dashboard's Inspection Routing chart counts Sell Raw vs Grade decisions.
  • You can re-route after the fact — open the card_instance and change its decision. Cost basis stays put.
  • Catalog matching — if Reactor can't find a known set code in the card name, you'll get an Unlinked prompt asking you to assign Game / Language / Set Code / Set Name.
