Locations

Physical storage spots — binders, slab boxes, shelves, card show table. Assign cards to a location so you can find them.

What you see

A tree of locations. Top-level entries (e.g. "Office", "Card Show Table") can have child sub-locations (e.g. "Office → Slab Binder 1", "Office → Slab Binder 2").

Each location has a type: graded, raw, or both. The slab modal only offers graded-type locations; the raw modal only offers raw-type.

Locations flagged is_card_show = true are special — when you assign a card to one of them, the card's is_card_show flag also flips.

Common actions

  • + Add Location — name + type. Optional parent for nesting.
  • Click a row — edit name, type, parent, card-show flag.
  • Delete — only allowed if no cards are assigned. Otherwise reassign first.

Assigning a card to a location

From the slab/raw detail modal, the Location field is a dropdown of valid locations for that card type. Saving fires /locations/assign which writes the assignment and optionally flips the card show flag.

Tips

  • Use a "Card Show Table" location with is_card_show = true as the canonical place to flag on-show inventory. Moving cards there automatically marks them on-show.
  • For grading-in-flight cards: a "Grading" location works well; remove the assignment when slabs come back.
