Listings

Active marketplace listings. eBay, TCGPlayer, Facebook, Instagram, etc. Three tabs: Graded, Raw, Graded Set.

What you see

Aggregated listing rows. Same card + platform + currency collapse into one row showing # Listed and # Sold. Click the chevron to expand into per-listing sub-rows.

  • Graded tab: rows are sku + grade + company + platform.
  • Raw tab: rows are sku + platform. Conditions and prices vary across sub-rows.
  • Graded Set tab: rows are listing_group_id. The whole set is one eBay listing.

Common actions

  • + Add Listing — list a card. Pick type (Graded single / Graded set / Raw), search for the card, pick the cert(s), set the price + eBay URL.
  • Click a sub-row — opens the Edit Listing modal scoped to that listing. Change URL, price, or cancel just that listing.
  • Cancel all — from the parent row's edit modal, cancel every listing in the aggregation.

FIFO + On Show

When listing a multi-copy graded card, the cert picker auto-selects via FIFO (oldest purchase date first) — but prefers non-on-show certs so you don't double-list one already on a card show table. An On Show badge appears on certs flagged is_card_show = true.

Tips

  • Order URL warning — if the URL you paste looks like a sold-order URL (not a /itm/ listing URL), Reactor shows an amber warning. eBay's sold order URLs aren't valid for active listings.
  • # Sold on a still-active set listing means a previous identically-composed set has been sold. Useful for spotting trends.
  • Cancelled listings aren't shown here — they live in the audit log.
