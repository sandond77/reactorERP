Import

Upload a CSV or Excel file. AI detects the type, proposes a column mapping, you review and confirm.

What you see

Two-column layout: main flow on the left (upload, Migration Guide on initial state; AI banner + column mapping + data preview during preview state), and a persistent Field Reference sidebar on the right.

The flow

  1. Upload a CSV or .xlsx. Any columns.
  2. AI detects the import type (Graded Cards / Raw Purchases / Bulk Sales / Expenses) with confidence high/medium/low.
  3. Mapping screen — every CSV column → a target field. Auto-mapped where confident; you fill in the rest. The Field Reference panel explains every field.
  4. Resolve prompts:
    • Language ambiguous — when a set code could be EN or JP, pick per row.
    • Unlinked rows — when a card has no matching set code at all, assign Game/Language/Set Code/Set Name.
  5. Confirm. The import runs; rows + errors get logged to Import History at the bottom.

Templates

The Templates dropdown on the upload screen downloads a canonical CSV for each import type. Recommended starting point for new users.

Migration Guide

The Migration Guide card on the upload screen lists all four import types side-by-side with "when to use this", required columns, recommended columns, and a per-type template download. Lets you pick the right one before fiddling with your CSV.
