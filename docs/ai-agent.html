AI Agent

Reactor has a built-in Claude-powered agent that can read your inventory and take actions on your behalf. It's not a chatbot grafted on top — it calls the same APIs the UI does.

How it works

The agent runs an agentic loop with up to 5 iterations. You send a message; the model decides if it needs to call a tool; if so it calls one (or several in parallel), reads the result, decides again. Loop ends when the model returns a final answer.

Under the hood it uses Anthropic Claude Sonnet for the main agent, with Claude Haiku doing a fast pre-screen on every message for abuse / off-topic content. Tool calls hit your normal app endpoints with your session — the agent only has access to data you have access to.

What it can do

Roughly: anything the app's UI lets you do. The agent has tools for:

  • Inventory — list, search, update, delete cards. Add raw purchases. Add graded cards directly.
  • Sales — record single sales, bulk card-show sales, edit existing sales, delete sales.
  • Listings — list, create, update, cancel.
  • Grading — submit cards to grading, list batches, update batch costs, process returns.
  • Trades — record card-for-card swaps.
  • Card shows — list shows, generate per-show P&L reports.
  • Expenses — record + delete expenses.
  • Locations — list locations, assign cards.
  • Catalog — look up Part #s.
  • Images — attach card scans uploaded with your message.

Full tool reference: AI Agent Reference.

What's enforced

  • Org scope — the agent only sees data scoped to your dataUserId. Other orgs are invisible.
  • State machine — same rules as the UI. Can't move a sold card back to raw_for_sale without going through a delete-sale.
  • Cost reconciliation — same. Agent edits to grading costs fan out to slabs + historical sales.
  • Audit log — every agent action is logged as actor = AI so you can distinguish them from your own.
  • Abuse pre-screen — Haiku checks every incoming message for prompt injection or off-topic content before the main loop fires.

When to use the agent vs the UI

Use the UI when:

  • You need to see a list and make decisions while looking at it (Listings, Sales, Raw Overall).
  • You're doing visual work (slab images, image uploads, location assignment via dropdowns).
  • You want speed for a one-off action you know exactly how to do.

Use the agent when:

  • You want a report ("P&L for last month", "show me my best ROI cards").
  • You're doing a multi-step action that would take several UI navigations.
  • You want to log something while in conversational flow ("just sold a Charizard at the show for $400").
  • You want to bulk-attach images you took on your phone.

Tips

  • Conversation history is kept locally in your browser. Refreshing keeps it; clearing site data resets it.
  • Card-show sales are easiest via the agent — "I sold cert 12345678 for $200 at Reading" parses cleanly.
  • If the agent does something wrong, ask it to undo. It has delete tools for sales / expenses / cards.
  • The agent can read but not delete trades. Trades require manual UI action for now.
