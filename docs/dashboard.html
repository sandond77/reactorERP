Dashboard

The home screen. Three tabs: Overview, Graded, and Raw Cards. Each one summarizes inventory + pipeline + sales for that segment.

Overview tab

Top-line numbers across the whole business: total inventory value, total sold YTD, profit, and the active order/grading pipeline.

  • Inventory value — sum of cost basis of every unsold card_instance.
  • Active grading — count + cost of cards in grading_submitted status.
  • Awaiting Intake (amber row) — sum of card_count from received raw_purchases that don't have matching card_instances yet. Tells you how many cards from received bulk lots are still un-split.

Graded tab

Same shape as Overview, scoped to graded slabs only. Pipeline shows ordered → received → graded → listed → sold.

Raw Cards tab

Scoped to raw inventory. The Pipeline column has stages Purchased / Inspected / For Sale / To Grade. Filter by Both / Raw / Bulk at the top to slice by purchase type.

  • Inspection Routing chart shows how many cards routed to Sell Raw vs. Grade after inspection.
  • Awaiting Intake on this tab is type-filtered (only counts the selected raw/bulk segment).

View toggles

Most rows have an All / Unsold / Sold toggle that switches the underlying query. Default is Unsold (current inventory).
