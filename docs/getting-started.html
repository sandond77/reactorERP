Getting Started

A fresh Reactor account has zero inventory. There are three paths to populate it; pick the one that fits how much existing data you have.

Path 1 — You have a spreadsheet

You've been tracking sales / purchases / inventory in Google Sheets, Excel, Numbers, or similar.

  1. Go to Import in the sidebar.
  2. Look at the Migration Guide — pick the import type that matches your sheet (Graded Cards, Raw Purchases, Bulk Sales, Expenses).
  3. Click Template next to that type to download the canonical CSV format.
  4. Reshape your sheet to match the template's columns. The Field Reference panel (right side of the page) explains every column.
  5. Upload your CSV. The AI auto-detects the import type and proposes column mappings. Review and adjust.
  6. Confirm. Reactor processes the file; rows appear under Graded/Slabs or Raw Cards immediately.

See CSV Import for the full reference.

Path 2 — You're entering inventory manually

If you have a small inventory, manual entry is often faster than wrestling with a CSV.

  • Graded slab: Graded/Slabs → + Add Slab. Enter cert #, grade, company, cost basis.
  • Raw purchase: Raw Cards → + Add Raw Purchase. Pick raw (single card) or bulk (multi-card lot).
  • Raw card from a bulk lot: Raw Cards → Inspection Panel → pick the lot → split out individual cards by condition + decision (sell raw / submit to grading).

Path 3 — You want to try Reactor with no real data

Use the AI Agent (bottom right) to populate test data:

"Add a raw purchase for 10 1999 Base Set cards at $200 total."

The agent calls the same APIs the UI uses, so anything it does is real and reversible.
