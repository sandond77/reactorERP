Expenses

Operating costs that aren't card cost basis — postage, supplies, subscriptions, booth fees. Hits overall P&L but not per-card profit.

What you see

One row per expenses entry. Columns: Date, Type, Description, Amount, Currency, Order #, Receipt link.

Common actions

  • + Add Expense — pick a type (Shipping, Supplies, Software, Fees, Travel, Other), enter amount + date + description + optional link.
  • Click a row — edit any field.
  • Bulk import — use the Import page with type Expenses. Required columns: description, amount, date.

What expenses DON'T do

  • Don't reduce total_cost_basis on cards. Per-card cost stays what it was.
  • Don't appear in card-level P&L reports. The Card Show Breakdown won't subtract booth fees from your show profit — you have to mentally reconcile.
  • Do show up in the overall Reports as an aggregate line item.

Tips

  • If a fee is per-card (e.g. PSA grading), don't log it here — log it as grading_cost on the submission so it lands in cost basis.
  • Booth fees + travel for card shows are good candidates here. Reconcile them against Card Show Breakdown profit to see true show net.
