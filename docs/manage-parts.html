Parts

The card catalog. Every distinct card the system knows about, identified by a SKU (Part #).

What you see

One row per card_catalog entry. Columns: SKU (Part #), Card name, Set name, Card number, Game, Language, Image URL.

The catalog is shared globally across users — it's not user-scoped. New cards get added when imports or manual additions encounter a name + set combo not already in the catalog.

Common actions

  • Search — by SKU, card name, or set.
  • Click a row — edit the canonical card name, set name, card number, image. Card_instances that reference this catalog row pick up the changes (display only — the override fields on individual cards stay).
  • Add image — upload a card scan that becomes the default thumbnail across the app.

SKU naming convention

Reactor's SKUs follow GAME-LANG-SETCODE-NUMBER, e.g. PKMN-JP-SV11B-088. The catalog tries to derive SKU from inputs; you can override.

Tips

  • Don't edit display names lightly — many existing card_instances reference this row. The display name change propagates everywhere.
  • If a card has a wrong set assignment, fix it in the catalog and all dependent card_instances will reflect the corrected set.
